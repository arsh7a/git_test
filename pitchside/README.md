# Pitchside

A football statistics website prototype: player profiles, percentile rankings,
player comparisons and a sortable statistics database.

> Out of the box the site shows **fictional sample data**, generated by the code
> in `src/data/sample/`. It can also load the **real 2015/16 season from
> StatsBomb Open Data** on your own computer (see below). That data is never
> committed to this public repository.

## Running it on your computer

You need [Node.js](https://nodejs.org) (the "LTS" version) installed once.
Then, in a terminal opened in this folder:

```bash
npm install
```

```bash
npm run dev
```

Open the address it prints (usually http://localhost:5173) in your browser.
Press `Ctrl + C` in the terminal to stop it.

To produce the finished website files (in the `dist` folder):

```bash
npm run build
```

## How the project is organised

| Folder / file | What it contains |
|---|---|
| `src/data/types.ts` | The *shape* of the data: players, clubs, leagues, season stats. |
| `src/data/sample/` | The sample-data generator (fictional names, clubs, stats). |
| `src/data/metrics.ts` | Every statistic: its label, explanation, formula, and which stats appear on radars, percentile panels and tables. |
| `scripts/statsbomb.ts` | Downloads StatsBomb Open Data and converts it to the site's format. |
| `src/data/source.ts` | Chooses real data (if downloaded) or sample data. |
| `src/data/index.ts` | **The single entry point for data.** Lookups, search, percentiles, similar players, leaderboards. |
| `src/components/` | Reusable pieces: charts, tables, search box, navigation. |
| `src/pages/` | One file per page: Home, Players, PlayerProfile, Compare, Stats, Leagues. |
| `src/styles/global.css` | All colours, fonts and layout. Colours are defined once at the top for light and dark mode. |

## Real data: StatsBomb Open Data, 2015/16

[StatsBomb Open Data](https://github.com/statsbomb/open-data) is free and needs
no account or key. It has every match of the 2015/16 Premier League, La Liga,
Serie A and Ligue 1 (Ligue 1 is missing 3 of its 380 matches; the Bundesliga
is left out because only Leverkusen's matches are published).

```bash
npm run data:statsbomb
```

This downloads each match's events (about 5 GB in total, a few minutes on a
fast connection), keeps only a small per-player summary of each match in
`data-cache/statsbomb/`, then writes the season to `src/data/real/dataset.json`.
Re-running skips matches already done; `npm run data:statsbomb -- --build-only`
rebuilds the season from the cache without downloading. Run the site as usual
afterwards. It uses the real data whenever that file exists; delete the file to
go back to sample data.

**StatsBomb's terms** (`LICENSE.pdf` in their repository): the data is for
research and non-commercial use; it may not be redistributed, which is why it
is not committed here; anything published from it must credit StatsBomb with
their logo, which the site shows in the footer. StatsBomb also asks users to
register at statsbomb.com/resource-centre.

**How the stats are counted.** Everything is calculated from StatsBomb's event
data. Minutes are scaled so a full match is 90. A few definitions are
Pitchside's own approximations of the usual ones:

- *Progressive pass*: completed, from outside the defending 40% of the pitch,
  at least 10 yards forward or into the penalty area (not corners or throw-ins).
- *Progressive carry*: at least 10 yards forward, ending in the opponent's half.
- *Touches*: completed ball receipts, set pieces taken, recoveries, clearances,
  successful interceptions and keeper claims.
- *Shot-/goal-creating actions*: the two attacking actions (completed passes,
  successful dribbles, shots, fouls won) before a shot or goal in the same
  possession.

Not in the open data, so hidden: match ratings, post-shot xG (so no "goals
prevented"), players' birth dates (so no ages) and heights.

### How the data switch works

Every page reads data through `src/data/index.ts`; `src/data/source.ts` picks
real or sample data. Any other provider only needs to produce the `Dataset`
shape from `src/data/types.ts`, listing the stats it measures in
`availableStats`; metrics, radars, tables and leaderboards that need anything
else are left out.

## Key definitions

- **Per 90**: a stat divided by minutes played, times 90, so that players with
  different playing time can be compared fairly.
- **Percentile**: the share of players in the same position group (with at least
  900 minutes that season) that this player outperforms on a stat.
