# Pitchside

A football statistics website prototype: player profiles, percentile rankings,
player comparisons and a sortable statistics database.

> Out of the box the site shows **fictional sample data**, generated by the code
> in `src/data/sample/`. It can also load **real data from API-Football** on your
> own computer (see below); that data is never committed to this public repository.

## Running it on your computer

You need [Node.js](https://nodejs.org) (the "LTS" version) installed once.
Then, in a terminal opened in this folder:

```bash
npm install
```

```bash
npm run dev
```

Open the address it prints (usually http://localhost:5173) in your browser.
Press `Ctrl + C` in the terminal to stop it.

To produce the finished website files (in the `dist` folder):

```bash
npm run build
```

## How the project is organised

| Folder / file | What it contains |
|---|---|
| `src/data/types.ts` | The *shape* of the data: players, clubs, leagues, season stats. |
| `src/data/sample/` | The sample-data generator (fictional names, clubs, stats). |
| `src/data/metrics.ts` | Every statistic: its label, explanation, formula, and which stats appear on radars, percentile panels and tables. |
| `scripts/` | Downloading API-Football data and converting it to the site's format. |
| `src/data/source.ts` | Chooses real data (if downloaded) or sample data. |
| `src/data/index.ts` | **The single entry point for data.** Lookups, search, percentiles, similar players, leaderboards. |
| `src/components/` | Reusable pieces: charts, tables, search box, navigation. |
| `src/pages/` | One file per page: Home, Players, PlayerProfile, Compare, Stats, Leagues. |
| `src/styles/global.css` | All colours, fonts and layout. Colours are defined once at the top for light and dark mode. |

## Real data from API-Football

You need a free API key from [api-football.com](https://www.api-football.com),
saved as the environment variable `API_FOOTBALL_KEY`.

1. Download a league-season into the local cache (`data-cache/`, not committed).
   It is safe to stop and re-run: anything already downloaded is skipped, and it
   stops by itself before using up the day's requests.

   ```bash
   npm run fetch:api -- --league 39 --season 2024
   ```

2. Turn the cache into the site's data file (`src/data/real/dataset.json`, also
   not committed). This makes no network requests and prints a quality report.

   ```bash
   npm run build:data
   ```

3. Run the site as usual. It uses the real data whenever that file exists;
   delete the file to go back to sample data.

**Free plan limits** (checked October 2026): 100 requests per day, 10 per
minute, seasons **2022, 2023 and 2024 only** (2024 = 2024-25), and the `page`
parameter can be at most 3. Because of the page limit, players are downloaded
per team: one league-season costs about 1 + 20 teams × 3 pages ≈ 62 requests,
so roughly one league-season per day. Useful league ids: 39 Premier League,
140 La Liga, 135 Serie A, 78 Bundesliga, 61 Ligue 1.

**What API-Football does not provide**, so the site hides it automatically when
running on real data: xG and xAG, progressive passes/carries/receptions,
shot- and goal-creating actions, touches, clean sheets, post-shot xG, aerial
duels, and a reliable pass completion rate. It adds average match rating and
duels won. Positions are only Goalkeeper / Defender / Midfielder / Forward,
so percentiles compare players within those four groups.

**Known data quirk:** API-Football sometimes files a player's season under the
club he plays for *now* (e.g. Kepa's 2024-25 loan season at Bournemouth appears
under Arsenal). `npm run build:data` flags such cases in its report.

### How the data switch works

Every page reads data through `src/data/index.ts`; `src/data/source.ts` picks
real or sample data. Any other provider only needs to produce the `Dataset`
shape from `src/data/types.ts`, listing the stats it measures in
`availableStats`; metrics, radars, tables and leaderboards that need anything
else are left out.

## Key definitions

- **Per 90**: a stat divided by minutes played, times 90, so that players with
  different playing time can be compared fairly.
- **Percentile**: the share of players in the same position group (with at least
  900 minutes that season) that this player outperforms on a stat.
